## Product requirements

- Build a new AI agent with Strands Agents during the Submission Period.
- The agent must do real work for real people and handle a task end to end, not merely chat.
- Standard tools, frameworks, libraries, templates, and AI coding assistants are allowed.
- Any other pre-existing code or work incorporated into the project must be disclosed.
- Third-party SDKs, APIs, and data require authorization and license compliance.
- The project must install and run consistently as depicted.
- Amazon Bedrock AgentCore is optional; a deployment can strengthen Technical Implementation.

Governor targets the Professional Agents track. The official description covers agents that make
professionals, makers, creators, and small-business owners better at repetitive or judgment-heavy
work.

## Submission requirements

- English submission materials.
- Text description explaining features and functionality.
- Public GitHub, GitLab, or Bitbucket repository.
- All source, assets, setup instructions, and material needed to run.
- MIT or Apache open-source license visible at repository top level.
- README and architecture diagram.
- Public YouTube or Vimeo demo video, maximum five minutes.
- Video must show the working project and pitch what it does, who it serves, and why it matters.
- AWS Builder ID.
- Free, unrestricted judging and testing access through the end of judging.
- Live demo is optional and can strengthen Technical Implementation.

## Judging

After a pass or fail viability stage, the official rules list five equally weighted criteria:

1. Technical Implementation
2. Design
3. Potential Impact
4. Creativity and Originality
5. Presentation

The architecture must therefore keep Strands central and non-trivial while remaining a coherent,
reproducible product with a clear professional problem and a visible end-to-end demo.

## AWS credits and cost

Registered participants may request USD 50 in AWS Promotional Credits while supplies last. The
official deadline is 2026-09-11 at noon PT, credits expire 2026-10-31, and additional charges remain
the entrant's responsibility. No credit, account, budget, or billing status is currently confirmed.

## Security and publication implications

- The public repository requirement does not authorize publishing the private GoNucleo factory.
- Testing access does not justify embedding credentials. The synthetic demo must work without
  private data or paid calls.
- A video and repository must not be made public without the owner's publication decision.
- The rules require original ownership and prohibit third-party IP or privacy violations.

## Changes discovered

No contradiction was found between the mission's dates and the official rules. This snapshot adds
judging dates, the public YouTube or Vimeo requirement, free testing through judging, credit expiry
on 2026-10-31, and the original-ownership requirement.
