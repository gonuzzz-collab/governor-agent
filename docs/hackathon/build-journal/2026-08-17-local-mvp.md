# 2026-08-17 - Local MVP Build Journal

## Built

Governor progressed from an isolated provenance boundary to a working local Strands agent. The
vertical slice now loads explicit governance, enforces hard gates, runs allowlisted validators,
records evidence, and produces safe, deny, or escalation outcomes.

## Important lessons

- Structured model output is not enough; every authority-relevant field must be compared with the
  deterministic decision.
- A deny path should stop before expensive validators when the permit already forbids the scope.
- Audit hashing must operate on the exact persisted JSON payload because unordered schema
  collections can change order during deserialization.
- A real-factory adapter should report missing contracts rather than invent filenames or schemas.
- A clean clone is stronger reproducibility evidence than a green test in the development tree.

## AWS and Strands notes

Strands 1.52.0 supports the required `Agent`, custom tools, typed hooks, model boundary, and current
structured-output invocation. Bedrock is available through the SDK provider, but no paid inference
was authorized or performed. This separation enables offline tests while preserving an AWS path.
