# AI System Card

## Purpose and limits

Governor supervises AI-assisted software changes under explicit policy and authority. It is not
authorized to invent policy, bypass deterministic gates, or perform unrestricted changes.

## Model, data, and configuration

No production model, dataset, or provider is enabled at this stage. The first tests use deterministic
doubles. Amazon Bedrock is the preferred contest provider but remains unconfigured.

## Evaluation and human oversight

Evaluation must cover correct tool selection, false allows, false denies, policy grounding, evidence
completeness, hallucinated policy, and unnecessary escalation. Humans retain final authority for
architecture, credentials, spend, publication, destructive actions, and material risk.
